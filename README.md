# MACIO — Enterprise Dashboards & Web Apps

MACIO is a high-performance portfolio platform showcasing specialized web solutions for enterprise environments. It demonstrates expertise in building scalable dashboards, modern landing pages, and premium web applications with a focus on clean UI/UX and robust performance.

## 🚀 Features

- **Dual-Variant Architecture**: Includes two distinct website designs—a modern "Glassmorphism" main variant and a professional "Studio/Enterprise" variant.
- **Dynamic Theming**: Full support for Dark and Light modes with persistent user preferences saved via `localStorage`.
- **Responsive Design**: Fully optimized for all device types, from mobile handsets to large enterprise monitors.
- **Formspree Integration**: Production-ready contact forms with real-time validation, sanitization, and automated email delivery.
- **Smooth Animations**: High-performance "reveal-on-scroll" effects powered by the Intersection Observer API.
- **Scroll Enhancements**: Features a custom scroll progress bar and smooth anchor-link navigation.
- **Automated CI/CD**: Integrated GitHub Actions workflow for seamless deployment to GitHub Pages on every push to the `main` branch.
- **Security First**: Configured with strict Content Security Policy (CSP) headers and SEO meta tags.
- **Direct Contact**: Includes a floating WhatsApp integration for immediate client engagement.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (CSS Variables), Vanilla JavaScript (Object-Oriented Design).
- **Icons**: Lucide Icons & optimized inline SVGs.
- **Typography**: Inter and Space Grotesk via Google Fonts.
- **Infrastructure**: GitHub Actions (CI/CD) and GitHub Pages (Hosting).

## 📁 Project Structure

- `index.html`: The primary portfolio landing page (Main Variant).
- `MACIO_Studio_Website.html`: The specialized enterprise/service variant.
- `app.js` / `style.css`: Core logic and styling for the main variant.
- `scripts.js` / `styles.css`: Specialized logic and styling for the Studio variant.
- `.github/workflows/deploy.yml`: Automated deployment configuration.

## 🌐 Deployment

The project is configured for GitHub Pages. Any changes pushed to the `main` branch trigger the `.github/workflows/deploy.yml` action, which automatically builds and deploys the site.
